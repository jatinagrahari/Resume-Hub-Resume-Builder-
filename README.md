## ✨ Features

- 📋 Multiple resume templates
- 📝 Dynamic resume form builder
- 👁️ Live resume preview
- 📥 PDF download support
- 💾 Save and manage resumes
- 🔐 User authentication
- 📱 Responsive design
- ⚡ Fast and lightweight UI
- 🎨 Modern interface using Tailwind CSS

---

## 🏗️ Architecture

### Frontend Stack
- **Framework:** React
- **State Management:** Zustand
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **HTTP Client:** Axios

### Backend Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **Authentication:** JWT

### Prerequisites
- Node.js (v16 or higher)
- MongoDB
- npm or yarn

#### Frontend Setup

```bash
